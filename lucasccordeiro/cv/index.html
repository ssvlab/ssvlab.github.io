Professional Summary

Tools

ESBMC: Efficient SMT-based Context-Bounded Model Checker for C, C++, CUDA, Python and Solidity. Award-winning at SV-COMP and Test-Comp since 2012.
FuSeBMC: White-box fuzzer combining bounded model checking, fuzzing and static analysis for test generation.
DSVerifier: Bounded model checker for digital systems with finite word length effects.
JBMC and Map2Check: Bounded model checking for Java bytecode, and unit test generation and memory safety checking for C.
