ESBMC Core Tool Updates & New Releases

ESBMC-PLC+: A Unified IEC 61131-3 Formal Verification Framework as a PLCverif Successor
Pierre Dantas, Lucas Cordeiro, Waldir Junior • arXiv (2606.23870) • 24 Jun 2026
Positions ESBMC-PLC+ as a successor to CERN's PLCverif, the most mature open-source PLC verification platform, by replacing its CBMC-only bounded-proof backend with ESBMC so unbounded k-induction proofs become possible. It unifies ESBMC's textual and graphical IEC 61131-3 Ladder Diagram frontends into a single verification framework aimed at industrial deployments.
https://arxiv.org/abs/2606.23870
ESBMC-GraphPLC: Formal Verification of Graphical PLCopen XML Ladder Diagram Programs Using SMT-Based Model Checking
Pierre Dantas, Lucas Cordeiro, Waldir Junior • arXiv (2606.18941) • 18 Jun 2026 (v2; originally submitted 17 Jun 2026)
Closes a gap in ESBMC-PLC where graphical PLCopen XML ladder-diagram exports from CONTROLLINO, Beremio, and OpenPLC Editor were silently parsed into an empty intermediate representation, producing vacuous verification passes. Adds a depth-first-search resolver over the rung connection graph plus a three-tier I/O inference scheme to recover correct rung logic.
https://arxiv.org/abs/2606.18941
ESBMC-PLC: Formal Verification of IEC 61131-3 Ladder Diagram Programs Using SMT-Based Model Checking
Pierre Dantas, Lucas Cordeiro, Waldir Junior • arXiv (2606.15461) • 13 Jun 2026
Introduces ESBMC-PLC, presented as the first open-source formal verifier with native support for IEC 61131-3 Ladder Diagram programs in the standard PLCopen XML format, added as a new ESBMC frontend. It models the PLC scan cycle as a nondeterministic while-loop and checks user-defined safety properties via bounded model checking or k-induction.
https://arxiv.org/abs/2606.15461

Kani: A Model Checker for Rust
Rémi Delmas, Zyad Hassan, Qinheping Hu, Rahul Kumar, Felipe R. Monteiro, Thanh Nguyen, Adrián Palacios, Celina Val, Michael Tautschnig, Justus Adam, Daniel Schwartz-Narbonne, Carolyn Zech • arXiv (2607.01504) • 1 Jul 2026
Describes Kani, an open-source Rust model checker that compiles MIR-level proof harnesses into CBMC's bit-precise verification engine, and extends checking from bounded to unbounded correctness via function/loop contracts, quantifiers, and function stubbing. Notable alongside ESBMC's own GOTO-Transcoder work, which proposes converting between CBMC- and ESBMC-format GOTO programs for the verify-rust-std project.
https://arxiv.org/abs/2607.01504
