ESBMC Core Tool Updates & New Releases

ESBMC-PLC+: A Unified IEC 61131-3 Formal Verification Framework as a PLCverif Successor
Pierre Dantas, Lucas C. Cordeiro, W. S. Silva Júnior • arXiv (2606.23870) • ~24 June 2026
Unifies ESBMC-PLC and ESBMC-GraphPLC and adds a Structured Text front end via the MATIEC compiler, so a single ESBMC-based backend now covers all three major IEC 61131-3 program formats. The authors position it as a successor to CERN's PLCverif, reporting large speedups and unbounded k-induction proofs on cases where PLCverif's BDD-based engine times out.
https://arxiv.org/abs/2606.23870

ESBMC-GraphPLC: Formal Verification of Graphical PLCopen XML Ladder Diagram Programs Using SMT-Based Model Checking
Pierre Dantas, Lucas C. Cordeiro, W. S. Silva Júnior • arXiv (2606.18941) • 17 June 2026 (rev. 22 June)
Extends ESBMC-PLC to the graphical (rung-and-coil) encoding of PLCopen XML Ladder Diagrams used by tools such as CONTROLLINO, Beremiz, and OpenPLC Editor. Adds a depth-first graph resolver that walks rung logic from the power rail to each coil, fixing cases where the original textual-only parser silently produced unsound “verified” results.
https://arxiv.org/abs/2606.18941
LinkedIn group: https://www.linkedin.com/groups/19070012/
ESBMC-PLC: Formal Verification of IEC 61131-3 Ladder Diagram Programs Using SMT-Based Model Checking
Pierre Dantas, Lucas C. Cordeiro, W. S. Silva Júnior • arXiv (2606.15461) • 13 June 2026
Introduces ESBMC-PLC, presented as the first open-source formal verifier with native support for IEC 61131-3 Ladder Diagram programs in PLCopen XML format, implemented as a new ESBMC front end. Across 13 benchmarks and 61 properties it correctly classified every case, surfacing 8 real bugs and 7 unbounded k-induction proofs.
https://arxiv.org/abs/2606.15461

Software Verification & Formal Methods

Neuro-Symbolic Software Verification: Hyper-charging Local Language Models with Symbolic Reasoning at Scale
Muhammad A. Pirzada, Julian Parsert, Weiqi Wang, Konstantin Korovin, Lucas C. Cordeiro • arXiv (2606.16886) • 15 June 2026
Presents VerIbMC, a pipeline pairing locally-run, open-weight language models with symbolic loop-invariant generation to scale up ESBMC-style bounded model checking without relying on any cloud API or proprietary model. Positioned as a neuro-symbolic augmentation of classic BMC pipelines rather than a replacement for them.
https://arxiv.org/abs/2606.16886
LinkedIn group: https://www.linkedin.com/groups/19070012/
Scalable Probabilistic Program Verification via Typed Extended Decision Diagrams
Daniel Basgöze, Kevin Batz, Sebastian Junges, Joost-Pieter Katoen • arXiv (2606.15043) • ~11–12 June 2026
Tackles state-space blow-up when computing weakest pre-expectations over partially unrolled loops in probabilistic programs, introducing “typed extended decision diagrams” plus SMT-based pruning. Reports order-of-magnitude scalability gains over prior deductive probabilistic-verification tools; a loose match to k-induction-style verification rather than a direct hit.
https://arxiv.org/abs/2606.15043

Verification Tools Landscape

Kani: A Model Checker for Rust
Rémi Delmas, Zyad Hassan, Qinheping Hu, Rahul Kumar, Felipe R. Monteiro, Thanh Nguyen, Adrián Palacios, Celina Val, Michael Tautschnig, Justus Adam, Daniel Schwartz-Narbonne, Carolyn Zech • arXiv (2607.01504) – accepted, ASE 2026 Industry Showcase Track • 1 July 2026
Describes Kani, an open-source bounded model checker for Rust that lowers proof harnesses from Rust MIR into CBMC's bit-precise SMT backend to check memory safety and panic-freedom without manual annotation. Reports industrial case studies with function/loop contracts that found six previously unknown bugs, and production CI use verifying over 16,000 harnesses per code change in the Rust standard library.
https://arxiv.org/abs/2607.01504
