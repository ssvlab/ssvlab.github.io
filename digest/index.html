ESBMC v8.4
ESBMC project team (University of Manchester / UFAM) • GitHub (Release) • 2026-07-06
Major release adding a CBMC GOTO-binary reader and a new ESBMC-PLC frontend for IEC 61131-3 Ladder Diagram verification. Pierre Dantas, Lucas Cordeiro, Waldir Junior • arXiv • 2026-06-24
Unifies textual and graphical Ladder Diagram plus Structured Text/SCL input formats behind a single ESBMC backend, adding k-induction-based unbounded safety proofs and modelling PLC timers, counters, and edge triggers as persistent scan-cycle state in ESBMC's GOTO IR.

Applications & Case Studies

ESBMC-Arduino: Closing the Deployment Gap for Formal Verification of Open-Hardware PLCs
Pierre Dantas, Lucas Cordeiro, Waldir Junior • arXiv • 2026-07-09
Extends ESBMC-PLC to real open-hardware PLC targets (OpenPLC, Arduino OPTA, CONTROLLINO, Industrial Shields M-Duino) via a hardware-abstraction-layer descriptor that checks arithmetic at true word width and realistic ADC ranges. On a 123-program corpus this eliminates all 54 false 16-bit-overflow alarms (a 44% false-alarm rate) without losing genuine-defect detection.
https://arxiv.org/abs/2607.08550

Symbolic Execution

Symbolon: Symbolic Execution by Learning Code Transformation
Jie Zhu, Penghui Li, Zhongxuan Li, Chihao Shen, Ziyang Li, Yizheng Chen, Kexin Pei • arXiv • 2026-06-27
Targets path-explosion and constraint-complexity bottlenecks in symbolic execution by learning reusable, context-sensitive program transformations offline on small programs, then applying them via an agent to larger repo-level targets. Evaluated on the KLEE engine across 16 search strategies and 32 real-world programs.
https://arxiv.org/abs/2606.29108

Verification Tools Landscape

Kani: A Model Checker for Rust
Rémi Delmas, Zyad Hassan, Qinheping Hu, Rahul Kumar, Felipe R. Monteiro, Thanh Nguyen, Adrián Palacios, Celina Val, Michael Tautschnig, Justus Adam, Daniel Schwartz-Narbonne, Carolyn Zech • arXiv • 2026-07-01
Presents Kani, an open-source bounded model checker for Rust that compiles proof harnesses from Rust MIR onto CBMC's verification engine. Reports industrial-scale use, including a Rust standard-library verification campaign running over 16,000 harnesses per code change, and case studies where contract-based verification found six previously unknown bugs.
